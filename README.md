# PrintHub

## Descripción

PrintHub es un proyecto de comercio electrónico especializado en impresoras 3D. La plataforma permite consultar y adquirir impresoras y productos relacionados con la impresión 3D de una forma sencilla y organizada.

## Objetivos

* Ofrecer diferentes modelos de impresoras 3D.
* Crear una plataforma web sencilla y fácil de utilizar.
* Permitir a los usuarios consultar productos y realizar compras.

## Instalación

Para instalar el proyecto, primero clona el repositorio y accede a la carpeta del proyecto:

```bash
git clone https://github.com/Jowy293/printhub.git
cd printhub
```

Después, instala las dependencias necesarias según la configuración del proyecto.

## Comando Linux

```bash
sudo apt update
```
